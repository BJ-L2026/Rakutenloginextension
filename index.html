乐天插件 - 隐私政策

最后更新日期：2026年08月24日

1. 概述

本隐私政策适用于 Chrome 浏览器扩展程序【乐天插件】（以下简称“本扩展”）。本页面完整、透明地披露本扩展数据收集、使用、存储、传输及数据共享全部规则，符合 Chrome 网上应用店用户数据政策（UDP）公开披露要求。

2. 已申请权限与功能用途（完全匹配 manifest）

本扩展仅申请实现核心业务必需的最小权限，无多余权限索取：

  • storage 权限：用于在用户本地浏览器保存插件功能配置、用户自定义设置，仅本地存储，不上传公网服务器。
  • host_permissions：http://192.168.0.3:8080/*：仅允许插件与用户个人内网本地服务进行数据交互，用于完成插件核心功能请求与数据展示，仅在用户主动使用插件时触发。

3. 数据收集说明

本扩展不会收集、读取、上传用户隐私信息，包括但不限于浏览历史、网站Cookie、账号密码、个人身份信息、通讯录、位置信息等敏感数据。

本扩展仅收集以下功能性业务数据：

  • 用户自定义插件配置数据（用于本地存储）；
  • 与内网服务 http://192.168.0.3:8080/* 交互产生的请求参数与业务返回数据（仅功能性交互数据）。

4. 数据使用用途

所有收集与交互的数据仅用于实现本插件核心功能，不会用于广告推送、用户画像、数据分析、营销推广等无关用途：

  • 本地存储数据：保存用户偏好设置，保证插件重启后配置不丢失；
  • 内网交互数据：完成插件与用户本地后台服务的业务通信、数据请求与功能渲染。

5. 数据存储方式与周期

  • 配置数据：存储于浏览器本地 chrome.storage.local，仅保存在用户设备本地，开发者无法读取、无法后台获取；用户卸载插件后，本地数据自动清除。
  • 接口交互数据：运行时临时内存处理，插件不持久化保存交互日志与接口数据。

6. 数据共享与数据接收方（审核必填完整披露）

本扩展严格遵守最小数据共享原则，完整披露数据流向如下：

  • 唯一数据接收方：用户自建内网服务 http://192.168.0.3:8080/*，无任何第三方平台、无公网服务器、无合作机构参与数据接收。
  • 无第三方共享：本扩展不会向任何第三方公司、机构、开发者服务器上传、分享、出售、泄露用户任何数据。
  • 除上述内网服务外，不存在任何数据分发、流转、共享行为。

7. 第三方服务声明

本扩展未集成任何第三方统计、埋点、广告、错误监控、用户分析、云服务SDK，零第三方数据收集行为。

8. 儿童隐私保护

本产品面向通用用户群体，不会主动收集13周岁以下未成年人的个人信息。

9. 用户数据权利

用户可随时通过浏览器扩展管理面板卸载本插件，卸载后所有本地存储数据将彻底清除。用户完全拥有自身数据的控制权与删除权。

10. 政策更新

我们可能根据功能迭代更新本隐私政策，更新后将修改页面最新日期，持续使用插件即视为认可更新后的隐私政策条款。
